# 🌐 Lochan Samser Rana Portfolio Website

A modern, responsive, and interactive personal portfolio website built using HTML, CSS, JavaScript, and Bootstrap 5. This portfolio showcases my skills, services, projects, and contact information with a professional UI/UX design.

## 📌 Features

* Modern Glassmorphism UI Design

* Dark / Light Theme Toggle
* Animated Background Particles
* Interactive Navigation (Single Page Application)

* Typing Text Animation
